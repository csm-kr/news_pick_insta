# 인기 카드뉴스 비주얼 패턴

성과와 원본 링크는 [인기 카드뉴스 벤치마크](../../plan-news-pick/references/popular-cardnews-benchmark.md)에서 확인한다. 새 run에서 스타일 이미지를 확보했다면 아래 portable 위치에서 직접 본다.

```text
<NEWS_PICK_OUTPUT_ROOT>/runs/<run_id>/references/style/
  <publisher>-<post-id>-slide-01.jpg ...
  popular-cardnews-manifest.json
```

이 자산은 해당 run의 레이아웃·위계·전개 참고용이다. 다른 machine에 과거 run이 없으면 아래 공개 링크와 구조 설명으로 다시 확보한다. 로고, 색 조합, 문구, 서체, 고유 그래픽을 복제하지 않는다.

## 방향 A — 인간 영향 포토뉴스

- 실제 기사 사진을 화면 전체에 사용한다.
- 하단 30~40%에 어두운 그라데이션과 2~3행 제목을 둔다.
- 첫 장은 `결과 + 비교 숫자`, 뒤 장은 사진마다 새 사실 한 문장으로 이어간다.
- BBC 북한 폭염과 시사IN 사건 현장 사례의 구조만 참고한다.

## 방향 B — 강조 답변형 해설

- 첫 장은 실제 사진 + 고대비 강조 블록으로 숫자와 결론을 함께 보여준다.
- 2~4장은 밝은 배경에 `질문 → 강조 답 → 근거 문단` 순으로 구성한다.
- 뉴닉 사례처럼 설명은 충분히 넣되, 본문이 4문단을 넘으면 기획으로 돌린다.

## 방향 C — 증거 주석형

- 실제 기사 사진·공식 공시·차트 중 하나를 화면의 주 증거로 삼는다.
- 박스, 기준선, 라벨, 화살표가 `어디를 봐야 하는지` 가리키게 한다.
- BBC 위성사진 사례처럼 `증거 → 관찰 → 제한적 해석`을 분리한다.
- 가짜 UI나 공시 화면을 새로 그리지 않는다.

## 생성 프롬프트 규칙

- 첫 reference: 같은 사건의 실제 기사 사진 또는 공식 화면. 내용·인물·장소의 기준이다.
- 다음 reference: 같은 사건의 보조 증거.
- 마지막 reference: 위 인기 카드뉴스 스타일 자산. 구성·시선 흐름만 참고하고 브랜드를 복제하지 않는다.
- `style reference에 보이는 로고·문구·서체·색을 출력하지 말 것`을 명시한다.
- 카드 1은 숫자만 크게 놓지 말고 독자에게 생기는 결과를 완전한 문장으로 넣는다.
- 카드 2~4는 각 장마다 앞 장에 없던 새 사실을 최소 하나 넣는다.

## 탈락 기준

- 첫 장이 `지표명 + 숫자`로 끝난다.
- 사진이 화면 아래 작은 장식으로만 쓰인다.
- 2장이 첫 장 수치를 반복할 뿐 맥락을 추가하지 않는다.
- 은행 로고·브랜드가 핵심 훅보다 더 눈에 띈다.
- 차트·공식·출처가 많아졌지만 독자가 얻는 답이 없다.
- 스타일 reference의 로고·브랜드·문구를 모방한다.
