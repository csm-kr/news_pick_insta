# 생성 카드 QA

## 자동 QA

- candidates PNG = 15
- 선택 slides PNG = 5
- 모든 결과 = 1080×1350 RGB/RGBA, 0바이트 아님
- 모든 생성 manifest의 `backend_request_size=1024x1536`, 기본 `resize_fit=cover`, 유효한 `backend_raw.path`·`raw_size`, `result_source=final`. 제한적 contain 폴백이면 raw·최종 sha256, 패딩 색, `fallback_reason=repeated_cover_crop_loss`가 추가로 있어야 함
- raw와 최종 결과 비교에서 중앙 4:5 crop이 제목·본문·표·로고·핵심 사진을 제거하지 않음
- job별 reference 경로와 생성 manifest 존재
- 선택 slide와 원본 candidate의 SHA-256 일치
- 선택 5장 상호 간 SHA-256 exact duplicate 없음
- 전체 이미지와 상단 60% 주요 영역의 dHash/MAE near duplicate 없음
- `pixel_modification=false`

## 확대 육안 QA

장면 중복 자동 검사는 사실 reference와 보조 스타일 reference를 구분한다. `references/style/` 아래의 보조 레이아웃·스타일 이미지는 사실 장면 매칭 풀에서 제외한다. 재생성에 사용한 완성 카드의 공통 타이포그래피가 서로 다른 기사 사진을 같은 장면으로 연결하지 않게 하기 위함이다. 첫 번째 대표 reference는 경로와 관계없이 계속 검사하며, 같은 사실 사진을 여러 카드가 재현하는 차단도 유지한다. 스타일·레이아웃 자료의 사진이나 인물을 결과물에 잘못 가져왔는지는 확대 육안 QA에서 별도로 확인한다.

- `required_text`의 모든 한글·숫자·단위·출처가 정확함
- 카드 2~4의 2~3문장 줄글·실제 이미지·표가 모두 존재함
- 카드 2~4의 표가 2~4행·최대 3열이고 이름/값 대응·정렬·단위가 정확함
- reference와 무관한 인물·건물·은행·문서·사건이 없음
- 기사 워터마크·가짜 뉴스 로고·랜덤 미세문자·깨진 한글이 없음
- 360px 폭에서 첫 제목과 핵심 수치가 2초 안에 읽힘
- 360px 폭에서 카드 2~4의 본문과 모든 표 셀, 카드 5의 모든 출처 행이 확대 없이 읽힘
- 상단·하단 72px을 가린 최종 안전영역 미리보기에도 모든 글자·숫자·표 테두리·로고가 온전히 남음
- 보존된 backend raw와 최종본을 함께 열었을 때 crop으로 사라진 핵심 요소가 없고, 패딩 띠나 비례축소로 가독성이 낮아지지 않음
- 첫 카드에서 결과·손실·격차·반전 중 하나가 기관명·정책명보다 먼저 읽힘
- 제목·핵심 숫자·대표 사진이 하나의 시선축을 만들고, 근거 없는 경고색·사이렌·비명형 장식이 없음
- 일반 텍스트 대비는 4.5:1을 목표로 함
- 마지막 카드의 `출처` 제목과 모든 출처명·날짜·도메인이 360px 폭에서도 판독됨
- 카드 1~4에 반복 출처 footer가 없고 카드 5에만 전체 출처가 있음
- 같은 사람·사건 사진·공식 화면이 유사 crop, 확대, 좌우 반전, 색 보정만 달리해 반복되지 않음
- 각 장의 주요 오브젝트·카메라 각도·배경 구도·표 형식이 실제로 다름
- 텍스트만 바뀌고 시각 서사가 같은 카드가 없음

한 항목이라도 실패하면 해당 카드를 모델로 재생성한다. 중복 실패는 겹친 장만 새 대표 reference와 visual role로 재생성한다. crop-safe 재생성에서도 같은 crop 손실만 반복되고 backend raw가 내용 QA를 모두 통과한 경우에만 배경색 매칭 좌우 contain 폴백을 1장에 한해 검수할 수 있다. 폴백은 새 픽셀 콘텐츠를 덧그리는 수정이 아니라 raw 전체를 보존하는 비례 축소·패딩이어야 하며, 띠 경계·축소 가독성·세트 리듬 중 하나라도 실패하면 사용하지 않는다. 코드로 글자나 표를 덮어 수정하지 않는다.
