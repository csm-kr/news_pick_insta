# 실제 기사 reference와 생성 카드 정책

## 기본 원칙

최종 카드는 생성 모델이 완성하지만 사실 근거는 생성하지 않는다. 모델에는 검증된 기사 대표 사진, 공식 발표·공시 화면, 잠긴 수치와 카피를 함께 제공한다. 결과는 원본 사진을 그대로 재게시하는 방식이 아니라 포토에디토리얼 인포그래픽으로 재구성한다.

## reference 우선순위

1. 공식 기관이 배포한 사진·보도자료 화면·공시 표
2. 선택 사건을 직접 다룬 언론 기사의 대표 사진과 기사 화면
3. 내용 이해에 필요한 지도·도표·문서 화면

검색 썸네일, 무관한 스톡 사진, 출처를 확인할 수 없는 이미지, 다른 사건 사진은 reference로 쓰지 않는다. 뉴스픽 계정에서는 한국경제·한경·한경BUSINESS를 source와 reference에서 제외한다.

## 세트 내 중복 금지

- 각 카드의 첫 reference는 서로 다른 이미지여야 하며 SHA-256이 같으면 생성 job을 만들지 않는다.
- 같은 인물이나 장소가 불가피하게 여러 근거에 등장해도 동일 사진·유사 crop·카메라 각도를 hero로 반복하지 않는다.
- 공통 공식 화면이나 기사 사진은 두 번째 이후 보조 reference로만 재사용하고 카드별 `visual_role`을 다르게 둔다.
- 생성 후 전체 이미지와 상단 주요 영역의 지각 유사도를 검사한다. exact/near duplicate는 자동 탈락한다.
- 자동 검사가 놓칠 수 있는 동일 인물·장면·오브젝트 반복은 사람이 확대 비교하고, 겹친 카드만 새 reference와 구도로 재생성한다.

## 모델이 해도 되는 일

- reference 사진을 크롭·톤 조정·콜라주하여 새로운 카드 구도로 재구성
- 잠긴 한글 카피·숫자·차트·공식을 최종 이미지 안에 직접 생성
- 공식 화면의 정보 구조를 참고해 읽기 쉬운 공공정보형 레이아웃 생성

## 모델이 하면 안 되는 일

- reference에 없는 인물·피해·현장·은행 표지·정당 로고·정부 문서를 발명
- 실제 기사 사진을 증거처럼 보이게 복제하면서 출처나 워터마크를 변조
- 잘못된 숫자·단위·은행명 대응·지도 경계를 시각적으로 그럴듯하게 채움
- 기사 사진과 무관한 추상 3D 오브젝트로 사건성을 대체

## 표시와 기록

- 카드 1~3에는 보이는 출처 footer를 두지 않는다. 마지막 카드에만 사용한 모든 출처의 `출처명 · 날짜 · 도메인` 블록을 읽을 수 있게 둔다.
- 캡션에는 `AI로 재구성한 인포그래픽`과 그 변형 문구를 넣지 않는다. AI 공개 표시는 Instagram의 `AI 콘텐츠` 라벨로 처리한다.
- `visual-manifest.json`에 reference 원본 경로·원문 URL·SHA-256을 보존한다.
- 사진 사용권이 불명확한 경우 reference는 내부 생성 입력에만 쓰고, 결과가 원본 사진을 사실상 복제하면 게시를 중단한다.

코드는 생성 결과의 크기·해시·장수·매니페스트를 검증할 뿐 한글·숫자·차트를 새로 그리지 않는다.
