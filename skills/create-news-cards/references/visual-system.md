# 비주얼 시스템과 세트 선택

- canvas: 1024×1024
- 안전 여백: 좌우 80~96px, 상하 72~96px
- 제목: 72~96px
- 부제: 38~48px
- 본문: 34~42px
- 출처·라벨: 26~30px
- 줄간격: 글자 크기의 1.35~1.5배
- 강조색: 방향당 1개
- 굵기: 기본/굵게 2종

세트 평가는 일관성, 사진-reference 적합성, 진행 다양성, 안전영역, 데이터 가독성, 왜곡 부재를 각각 0~2점으로 합산한다. 12점 중 9점 미만은 탈락한다. 최고 두 세트의 차이가 1점 이하이면 자동 선택하지 않는다.

한 카드의 우선순위는 `결론 1 → 근거 2~3 → 출처·기준시각`이다. 본문이 넘치면 글자를 줄이지 말고 기획 단계로 돌린다.

생성 모델이 사진·한글·수치·차트를 포함한 완성 이미지를 만든다. 포토에디토리얼 영역은 카드 면적의 약 25~40%를 사용하고, 나머지는 큰 제목과 한 개의 핵심 표·차트에 배분한다. 코드는 시각 요소를 추가하지 않는다.
