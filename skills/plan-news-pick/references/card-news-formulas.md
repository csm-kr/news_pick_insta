# 카드뉴스 구성 공식

## 5장 고정

1. Cover: 실제 사진 + 하단 그라데이션 + 결과형 2행 제목 + 짧은 조건/기준시각
2. Facts: 2~3문장 줄글 + 관련 실제 이미지 + 2~4행 핵심 사실표
3. Context: 2~3문장 줄글 + 다른 실제 이미지 + 단순 비교표
4. Impact: 2~3문장 줄글 + 다른 실제 이미지 + 영향/입장/미정 비교표
5. Sources: 출처명·날짜·도메인, 기준시각, 정정 경로 전용

## 세트 내 시각 중복 방지

- 장마다 고유한 `visual_role`을 쓴다. 정보 역할 이름이 아니라 실제 화면 문법까지 적는다.
- 권장 흐름은 `하단 그라데이션 사진 표지 → 사실표 → 비교표 → 영향표 → 출처 전용 카드`다.
- 같은 대표 사진, 같은 인물 크롭, 같은 카메라 각도, 같은 배경, 같은 표 형식, 같은 텍스트 패널 배치를 연속 사용하지 않는다.
- 색·서체·그리드는 세트 일관성을 만들고, 반복된 hero 이미지나 레이아웃은 일관성 수단으로 쓰지 않는다.
- 공통 reference가 꼭 필요하면 보조 근거로만 두고 카드별 첫 reference는 서로 다른 이미지로 정한다.
