# 소스 레지스트리

`source-registry.json`에는 실측한 RSS만 기본 활성화한다. URL을 추측해 추가하지 않는다.

등록 전 health check:

- HTTP 200뿐 아니라 예상 feed title과 item 존재
- 최근 항목의 날짜 파싱 가능
- 원문 URL과 발행처가 일치
- 오류 페이지가 아닌 충분한 content length
- 문자 인코딩 정규화 가능

연합뉴스의 여러 feed는 발견 범위를 넓히지만 독립 언론 수 계산에서는 모두 한 발행처다. 연합뉴스TV도 같은 통신사 계열일 수 있으므로 핵심 교차검증에서는 보수적으로 별도 독립성을 주장하지 않는다.

종합 feed와 같은 발행처의 정치·경제 분야 feed를 동시에 활성화하면 해당 분야가 후보 수에서 중복 가중된다. 기본 registry는 종합 feed만 활성화하고 분야별 feed는 진단용으로 보존한다. 대중 관심형 후보가 부족할 때도 분야별 feed를 임의로 켜지 말고, 검증된 종합 RSS 또는 원문 검색의 회수 범위를 넓힌다.

공식 목록은 정책브리핑과 국토교통부부터 시작하고, 정치·재난·통계 사건에 필요한 기관을 사건별로 추가한다. 공식 발표는 정부 주장 자체의 원문이지 정책 효과에 대한 독립 검증을 대신하지 않는다.
