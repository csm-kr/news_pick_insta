# 비주얼 시스템과 세트 선택

- canvas: 1080×1350
- 제작 안전영역: 좌우·상하 72px. 모든 글자·숫자·표 테두리·로고는 최종 `x=72..1008`, `y=72..1278` 안에 완전히 포함한다. 보존된 backend raw와 최종 cover 결과를 비교해 중앙 4:5 crop이 핵심 요소를 자르지 않았는지 확인한다.
- 표지 제목: 86~108px, 2행 이내
- 본문 제목: 58~72px
- 부제: 38~48px
- 본문: 34~40px
- 표·출처·라벨: 30~36px
- 줄간격: 글자 크기의 1.35~1.5배
- 강조색: 방향당 1개
- 굵기: 기본/굵게 2종

세트 평가는 일관성, 사진-reference 적합성, 진행 다양성, 안전영역, 360px 본문·표 가독성, 왜곡 부재를 각각 0~2점으로 합산한다. 12점 중 9점 미만은 탈락한다. 최고 두 세트의 차이가 1점 이하이면 자동 선택하지 않는다.

한 카드의 우선순위는 `결론 1 → 근거 2~3 → 출처·기준시각`이다. 본문이 넘치면 글자를 줄이지 말고 기획 단계로 돌린다.

생성 모델이 사진·한글·수치·표를 포함한 완성 이미지를 만든다. 1장은 사진 전면+하단 그라데이션을 고정하고, 2~4장은 실제 이미지 35~50%, 줄글 한 문단, 표 하나를 명확히 분리한다. 5장은 출처 전용이다. 코드는 시각 요소를 추가하지 않는다.
