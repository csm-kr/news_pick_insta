# 인기 카드뉴스 비주얼 패턴

성과와 원본 링크는 [인기 카드뉴스 벤치마크](../../plan-news-pick/references/popular-cardnews-benchmark.md)에서 확인한다. 새 run에서 스타일 이미지를 확보했다면 아래 portable 위치에서 직접 본다.

```text
<NEWS_PICK_OUTPUT_ROOT>/runs/<run_id>/references/style/
  <publisher>-<post-id>-slide-01.jpg ...
  popular-cardnews-manifest.json
```

이 자산은 해당 run의 레이아웃·위계·전개 참고용이다. 다른 machine에 과거 run이 없으면 아래 공개 링크와 구조 설명으로 다시 확보한다. 로고, 색 조합, 문구, 서체, 고유 그래픽을 복제하지 않는다.

## 모든 디렉터의 고정 표지

- 1장은 실제 기사 사진을 전면에 쓰고 하단 35~42%에 어두운 그라데이션을 올린다.
- 제목은 하단 그라데이션 안의 좌측 정렬 2행 이내, 부제·상태·기준시각은 그 아래에 둔다.
- 상단 제목 패널, 중앙 포스터 제목, 작은 사진 장식형 표지는 금지한다.
- 아래 10개 디렉터는 팔레트·타입·2~4장 전개만 바꾸며 이 표지 구조를 바꾸지 않는다.

## 방향 A — 인간 영향 포토뉴스

- 본문에서도 실제 기사 사진을 가장 큰 시각 증거로 사용한다.
- 첫 장은 `사람의 결과 + 비교 숫자/격차/반전`을 가장 큰 덩어리로 만들고, 기관명과 배경 설명은 작게 내린다. 뒤 장은 사진마다 새 사실 한 문장으로 이어간다.
- BBC 북한 폭염과 시사IN 사건 현장 사례의 구조만 참고한다.

## 방향 B — 강조 답변형 해설

- 2~4장은 밝은 배경에 `질문 → 강조 답 → 근거 문단 → 표` 순으로 구성한다.
- 뉴닉 사례처럼 설명은 충분히 넣되, 본문이 4문단을 넘으면 기획으로 돌린다.

## 방향 C — 증거 주석형

- 실제 기사 사진·공식 공시·단순 표 중 하나를 화면의 주 증거로 삼는다.
- 박스, 기준선, 라벨, 화살표가 `어디를 봐야 하는지` 가리키게 한다.
- BBC 위성사진 사례처럼 `증거 → 관찰 → 제한적 해석`을 분리한다.
- 가짜 UI나 공시 화면을 새로 그리지 않는다.

## 방향 D — 숫자 우선 비주얼 브리프

- 본문은 검증된 숫자 하나와 그 뜻을 먼저 보여주고, 실제 이미지·짧은 줄글·표로 근거를 이어간다.
- 숫자 주변에 충분한 여백을 두고 단위·기준 기간·대상을 붙인다.

## 방향 E — 절차 타임라인

- 날짜·단계·현재 상태를 큰 지점으로 연결하고 실제 이미지와 2~4행 시간표를 결합한다.
- 미확정 단계는 `논의 중`, `심사 중`, `시행 전`처럼 상태를 명시한다.

## 방향 F — 분할 대조 에디토리얼

- 전후·입장·기대와 우려를 두 영역으로 나누고 주체를 바로 붙인다.
- 중앙 설명 한 문단과 하단 비교표가 같은 결론을 가리키게 한다.

## 방향 G — 타이포그래피 뉴스 포스터

- 본문 제목의 크기 대비를 강하게 쓰되 줄글·실제 이미지·표를 생략하지 않는다.
- 장식용 미세문자와 작은 패널 묶음을 쓰지 않는다.

## 방향 H — 질문·답변 미니멀

- 독자가 실제로 물을 질문 하나와 검증된 답 하나를 주 시선축으로 둔다.
- 답 아래에 2~3문장 줄글, 실제 이미지, 근거표를 간결하게 배치한다.

## 방향 I — 모듈 체크리스트 브리프

- 상태를 3~5개 모듈로 구분하되 본문 줄글은 하나의 문단으로 유지한다.
- 실제 이미지와 2~4행 상태표를 위에서 아래로 읽는 순서에 맞춘다.

## 방향 J — 비대칭 매거진 컷아웃

- 실제 기사 사진의 핵심 인물·사물을 한쪽에 크게 두고 반대쪽에 제목·줄글·표를 정렬한다.
- 비대칭 긴장감이 가독성을 해치거나 사진을 장식으로 만들지 않게 한다.

## 생성 프롬프트 규칙

- 위 10개 디렉터를 전체 풀로 두고 새 work-dir마다 시드 기반으로 3개를 중복 없이 무작위 선택한다.
- 선택 디렉터와 시드를 generation plan·visual manifest에 기록하고 같은 work-dir에서 바꾸지 않는다.
- 첫 reference: 같은 사건의 실제 기사 사진 또는 공식 화면. 내용·인물·장소의 기준이다.
- 다음 reference: 같은 사건의 보조 증거.
- 마지막 reference: 위 인기 카드뉴스 스타일 자산. 구성·시선 흐름만 참고하고 브랜드를 복제하지 않는다.
- `style reference에 보이는 로고·문구·서체·색을 출력하지 말 것`을 명시한다.
- 카드 1은 숫자만 크게 놓지 말고 독자에게 생기는 결과를 완전한 문장으로 넣는다.
- 카드 1의 제목·핵심 숫자·대표 사진이 한 번에 보이는 단일 시선축을 만들고, 작은 패널과 장식으로 긴장감을 분산시키지 않는다.
- 신호색은 핵심 결과 한 곳에만 사용한다. 위험·위법이 확인되지 않은 사안에 경고 삼각형, 사이렌, 화염, 깨지는 효과를 쓰지 않는다.
- 카드 2~4는 각 장마다 앞 장에 없던 새 사실을 최소 하나 넣는다.
- 카드 2~4는 `2~3문장 줄글 + 관련 실제 이미지 35~50% + 2~4행·최대 3열 표`를 모두 포함한다.
- 카드 5는 출처명·날짜·도메인·기준시각·정정 경로만 크게 정리한다.
- 360px 폭에서 본문과 표 셀을 읽기 어렵다면 실패다.

## 탈락 기준

- 첫 장이 `지표명 + 숫자`로 끝난다.
- 사진이 화면 아래 작은 장식으로만 쓰인다.
- 2장이 첫 장 수치를 반복할 뿐 맥락을 추가하지 않는다.
- 은행 로고·브랜드가 핵심 훅보다 더 눈에 띈다.
- 표·출처가 많아졌지만 독자가 얻는 답이 없다.
- 스타일 reference의 로고·브랜드·문구를 모방한다.
- 본문이 칩·구호·미세문자로 흩어지거나 표 셀을 읽을 수 없다.
- 5장에 새 주장·CTA가 들어가거나 1~4장에 출처 footer가 반복된다.
