# 뉴스픽 운영 정책

- 대상: 한국 20~60대. 특정 정치 성향보다 여러 연령대의 일상 체감·대화 가치·설명 가능성을 우선한다.
- 범위: 생활경제·소비자·사회·건강·과학기술·교통·문화·스포츠·환경·국제·정치·부동산을 포함한 종합 이슈
- 기본 편성: 하루 3건, `popular_interest` 2건(07:00·12:00) : `public_impact` 1건(17:00)
- 대중 관심형 기준: 생활 관련성·대화 가치·4장 설명력·새로움을 각 0~3점으로 평가하고 합계 8/12 이상
- 반복 억제: 최근 공개 게시물 6건과 오늘 게시물을 확인해 같은 사건을 제외하고 같은 대분류의 연속 편성을 강하게 감점
- 정치·부동산 상한: 두 분야 합계 하루 1건, 연속 게시 금지. 전국적 긴급성 또는 즉시 권리·비용 변화가 명확한 확정 사안만 예외
- 비선정: 연예인 사생활·확인되지 않은 논란·단순 경기 결과·자극적 범죄 소비는 대중 관심형으로 취급하지 않음
- 회차: 07:00, 12:00, 17:00 KST
- 준비 시작: 각 회차 30분 전인 06:30, 11:30, 16:30 KST
- 형식: 핵심 사건 하나, 3~4장 1024×1024 정방형 캐러셀
- 톤: 중립적이고 강한 사실형 후킹
- 계정: run의 `account`와 `IG_ACCOUNT`로 설정. 현재 운영 기본값은 `@newspick_studio`
- 수동 모드: exact payload hash를 확인하고 건별 승인
- 예약 모드: `07:00`, `12:00`, `17:00` KST 회차에 한해 정책 전체를 standing approval로 승인. 모든 QA를 통과한 exact payload를 회차당 한 번만 게시
- 이미지 생성 승인: 예약 run의 `references/content`와 `references/style` 아래 공개 기사·공식·스타일 이미지만 Tibo/GPT Image 백엔드로 보내 정확히 12장 후보를 만드는 범위에 standing approval 적용. 인증·세션·개인정보·그 밖의 로컬 파일 전송 금지
- 게시 시각 게이트: 제작·QA가 일찍 끝나도 회차 시각 전에는 `공유하기`를 누르지 않음
- missed run: 회차 시각 뒤 30분을 넘기면 보충 게시하지 않고 건너뜀
- 무인화 hard stop: target editorial lane에 맞는 새 이슈 부재, 중복·과다 반복 주제, 근거·기획·이미지·로그인·계정·캐러셀·AI 라벨 QA 실패는 게시 없이 `skipped` 또는 `needs_review`
