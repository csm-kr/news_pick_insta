# 뉴스픽 운영 정책

- 대상: 한국 20~60대. 특정 정치 성향보다 여러 연령대의 일상 체감·대화 가치·설명 가능성을 우선한다.
- 범위: 생활경제·소비자·사회·건강·과학기술·교통·문화·스포츠·환경·국제·정치·부동산을 포함한 종합 이슈
- 기본 편성: 하루 3건, `07:00 entertainment` : `12:00 hot_news_week`(분야 제한 없는 최근 7일 최고 반응) : `17:00 hot_news_3day`(분야 제한 없는 최근 3일 최고 반응), 2026-10-14 사용자 지시
- 아시안게임 기간 편성: 2026-09-27~10-02의 07:00은 `asian_games`(한국 선수단 확정 결과·기록), 사용자 지시로 10-03부터 조기 종료하고 다시 `entertainment`
- 검색 범위: 07시는 직전 48시간, 12시는 7일, 17시는 3일을 기본으로 하며 그 안에서 지난 뉴스도 현재 공개 반응이 더 크면 선택 가능
- 선택 우선순위: 증거 완성도 필수 통과 → 공개 반응·확산·대화 열기·지속성 → 후킹 잠재력 → 생활/공공 영향·5장 설명력 → 최신성 (2026-10-14 사용자 지시 "후킹이 되는 뉴스")
- 대중 관심형 기준: 생활 관련성·대화 가치·5장 설명력·새로움을 각 0~3점으로 평가하고 합계 8/12 이상
- 반복 억제: 최근 공개 게시물 6건과 오늘 게시물을 확인해 같은 사건을 제외하고 같은 대분류의 연속 편성을 강하게 감점
- 정치 편성: 핫뉴스 회차에서 가장 반응이 큰 사건이 정치일 때만 하루 1건으로 다루고 07:00 연예 회차에는 넣지 않는다.
- 연예 watchlist: `scheduled_runner.py`의 `ENTERTAINMENT_WATCHLIST`(현재 리센느)에 있는 아티스트·작품의 검증된 사건은 연예 회차에서 최우선 후보로 비교한다. 증거 조건은 동일하다.
- 12:00 핫뉴스는 오늘 07:00 사건을, 17:00 핫뉴스는 오늘 07:00·12:00 사건을 제외한다.
- 비선정: 연예인 사생활·확인되지 않은 논란·단순 경기 결과는 대중 관심형으로 취급하지 않음. 07:00 연예 회차는 자극적 범죄 소비도 제외
- 강력범죄: 12:00·17:00 핫뉴스에서만 경찰·검찰·법원 발표 또는 독립 언론 두 곳으로 확인된 사건을 후보로 비교. 피해자 신상·유족 사생활·잔혹한 수법 묘사·확정되지 않은 피의자 실명과 얼굴, 피해 현장·피해자 사진은 쓰지 않음
- 회차: 07:00 연예, 12:00 연예, 17:00 최고 반응 이슈 KST · Story 19:00 KST
- 준비 시작: 각 회차 30분 전인 06:30, 11:30, 16:30 KST
- 07시 연예 후보 확장: 기본 검색창에 적격 사건이 없으면 하루씩 최대 30일을 역추적한다. 가능한 경우 검증 사건 3건을 모아 임팩트를 비교하며, 첫 적격 사건이나 최신 기사라는 이유만으로 선택하지 않는다.
- 07시 선택 우선순위: 증거 완성도 필수 통과 → 공개 반응·대중 파급 범위·확정 결과/수치의 크기·대화 가치·5장 설명력 → 후킹 잠재력 → 최신성. 검색 범위와 비교 결과를 산출물에 기록한다.
- 형식: 핵심 사건 하나, 5장 1080×1350 세로형 캐러셀. 하단 그라데이션 사진 표지 → 줄글+이미지+표 본문 3장 → 출처 전용 카드
- 톤: 결과·손실·격차·반전을 전면에 두는 고강도 사실형 후킹. 제목은 세게, 부제는 조건·범위를 정밀하게 제한
- 계정: run의 `account`와 `IG_ACCOUNT`로 설정. 현재 운영 기본값은 `@newspick_studio`
- 수동 모드: exact payload hash를 확인하고 건별 승인
- 예약 모드: `07:00`, `12:00`, `17:00` KST 회차에 한해 정책 전체를 standing approval로 승인. 모든 QA를 통과한 exact payload를 회차당 한 번만 게시
- 이미지 생성 승인: 예약 run의 `references/content`와 `references/style` 아래 공개 기사·공식·스타일 이미지만 Tibo/GPT Image 백엔드로 보내 정확히 15장 후보를 만드는 범위에 standing approval 적용. 인증·세션·개인정보·그 밖의 로컬 파일 전송 금지
- 게시 시각 게이트: 제작·QA가 일찍 끝나도 회차 시각 전에는 `공유하기`를 누르지 않음
- missed run: 회차 시각 뒤 30분을 넘기면 보충 게시하지 않고 건너뜀
- 무인화 hard stop: target editorial lane에 맞는 새 이슈 부재, 중복·과다 반복 주제, 근거·기획·이미지·로그인·계정·캐러셀·AI 라벨 QA 실패는 게시 없이 `skipped` 또는 `needs_review`

언론 기사와 공식 발표만 사실 근거로 허용한다. 포털 랭킹·댓글·공감·공유·검색 추세·공개 소셜 반응은 뉴스 선택 신호로는 허용하지만 사건 사실 근거로는 허용하지 않는다. X·소셜·커뮤니티·검색 스니펫·AI 생성 텍스트는 사실 근거가 아니다.
