## 분석 방법과 한계

YouTube 플레이어에서 한국어 자동 생성 자막 트랙이 존재하는 것을 확인했다. 그러나 공식 `timedtext` 응답은 200이면서 본문이 비었고, `get_transcript`는 400 `FAILED_PRECONDITION`, 화면의 스크립트 패널은 열렸지만 세그먼트가 내려오지 않았다. 따라서 자막 원문 전체를 확보했다고 주장하지 않는다.

대신 플레이어가 공식 제공하는 최고 해상도 스토리보드 레벨을 사용해 10초 간격 120프레임을 내려받았다. 각 프레임에 보이는 화면·자막 문구를 시간 순서대로 확인했다. 원본 시트는 `.local/youtube-analysis/storyboards-l3/`에 보존한다.

## 핵심 교훈

1. 계정 소개는 짧고 구체적이어야 한다. “무엇을, 누구에게, 얼마나 자주”를 바로 보여준다.
2. 카드 디자인만 괜찮아서는 성장하지 않는다. 주제 선택과 첫 화면 후킹이 더 중요하다.
3. 카드뉴스와 릴스는 노출 구조가 다르다. 동일 KPI로 평가하지 않는다.
4. 평균 조회수와 바이럴 한 건을 분리한다. 대시보드 총조회만으로 성공을 판정하지 않는다.
5. 자동화는 자료조사·검증·게시 확인까지 포함해야 한다. 생성만 자동화하면 오보와 무관한 비주얼이 남는다.
